# Probably Just a Rat

Призраки последних видимых позиций врагов для **Foundry VTT 14**. Любая игровая система; требуется зрение токена.

![Призраки последних видимых позиций врагов](media/demo.webp)

Призрак остаётся там, где врага видели в последний раз, и исчезает при повторном обнаружении. У каждого игрока своя память, сохраняющаяся после F5. По умолчанию позиции забываются через два раунда боя или одну минуту вне боя; завершение боя очищает память.

Кнопка с крысой открывает пинг, переход камеры и удаление позиций.

Панель объясняет, когда память отключена, требует боя или не имеет источника зрения. Сводка правил учитывает сохранённые настройки мира и сцены; подробности доступны при наведении. ГМ может **Скопировать отчёт для поддержки** с версиями, правилами и состоянием наблюдения, без документов мира и запомненных позиций. Если буфер обмена недоступен, панель показывает текст для ручного копирования. Автоматической отправки нет.

В настройках модуля ГМ выбирает вид маркера для всех игроков: **Призрак**, **Следы ботинок**, **Метка позиции** или **Своя картинка**. Опция **Поворачивать по движению** разворачивает любой маркер по последнему наблюдаемому направлению движения токена; после потери видимости угол фиксируется. По умолчанию выключена.

По умолчанию скрытие токена через **Hidden** удаляет его сохранённую позицию. ГМ может включить сохранение известных позиций. Ранее не виденные токены не создают маркеры. В бою подпись последней позиции остаётся рядом со счётчиком раундов.

Память учитывает зрительное обнаружение: темноту, тёмное зрение и **See Invisibility**. Для See Invisibility та же точка должна быть доступна тому же наблюдателю по обычному зрению или освещению. Слух, виброчувствительность и другие незрительные чувства не обновляют память. В PF2e и Starfinder 2e включите **Rules-Based Vision**, чтобы использовать автоматизацию чувств и состояний системы; состояние **Hidden** в PF2e отличается от кнопки **Hidden** у ГМ.

В официальной системе **Daggerheart** настройка **Память в столкновении** предлагает **После N шагов spotlight** (сохраняет прежний срок, по умолчанию 2) или **До конца столкновения** (рекомендуется). Назначение, переключение и снятие spotlight считаются шагами. Во втором режиме числовой срок и счётчик шагов скрыты; повторное обнаружение и ручное удаление убирают отметки, вне столкновения действует срок в минутах. **Долгая память** сцены имеет приоритет. Состояние **Hidden** в Daggerheart само не скрывает токен на карте: используйте кнопку **Hidden** у ГМ и правило **Сохранять отметку**, чтобы оставить уже известную позицию.

ГМ может открыть вкладку **Видимость** текущей сцены кнопкой в разделе **Правила памяти**.

В **Настройках сцены → Видимость** можно выбрать правила мира, отключить память или включить **Долгую память**. Она сохраняет известные позиции при Hidden, смене боя и после F5 — до повторного обнаружения или ручного удаления.

![Режим памяти сцены на вкладке «Видимость»: выбрана долгая память](media/memory-mode.webp)

В настройках доступны разделы **Маркер**, **Правила памяти**, **Подписи и пинги**. В разделе **Маркер** есть предпросмотр оформления даже без запомненных врагов. В разделе **Общие** каждый игрок может выбрать язык модуля.

Для своего маркера выберите **Своя картинка** и укажите **Файл изображения** в настройках модуля.

![Маркер со своей картинкой](media/custom-image.webp)

Установите модуль из [каталога Foundry](https://foundryvtt.com/packages/probably-just-a-rat): откройте **Модули → Установить модуль** и найдите **Probably Just a Rat**. Затем включите модуль в мире.

Также можно вставить эту ссылку в поле **URL манифеста**:

```text
https://github.com/wondersalmon/probably-just-a-rat/releases/latest/download/module.json
```
