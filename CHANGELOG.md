# Changelog

## 0.1.1

- Added manual GitHub release builds from an existing tag, with tag and package-version validation.
- Updated development dependencies; kept Pixi 7 and disabled its automatic major updates.

## 0.1.0

First public release for Foundry VTT 14.

- Client-local ghosts at last-seen enemy positions, restored after F5 and removed on rediscovery or expiry.
- Token-tool panel and combat-tracker pings for remembered positions; optional Adventurer HUD integration.
- Personal opacity, grayscale, outline and caption settings. GM rules for names, round counters, ping audience and combat-only mode.
- Per-token overrides, clear-memory keybinding and English/Russian localization.
- GM-configurable memory lifetime: default 2 combat rounds and 1 minute outside combat.
